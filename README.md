# Investment Radar Skills

公开的 OpenClaw Skills 合集，用于投资研究监控。

## Skills

| Skill | 用途 |
|-------|------|
| [a-stock-radar](a-stock-radar/) | A股行情监控（东方财富/新浪API） |
| [hk-stock-radar](hk-stock-radar/) | 港股行情与舆情监控 |
| [crypto-radar](crypto-radar/) | 加密货币行情（BTC/ETH/SOL等） |
| [fx-radar](fx-radar/) | 全球汇率监控（美元/人民币/欧元等） |
| [futures-radar](futures-radar/) | 期货与大宗商品行情（黄金/原油/铜） |
| [us-stock-radar](us-stock-radar/) | 美股行情（标普/纳指/道指/VIX/期货） |

## 安装

从 ClawHub 安装：
```
clawhub install <slug>
```

或 clone 本仓库到 `~/.openclaw/workspace/skills/`
